# Realistic adult game characters

These three fully clothed, rigged GLB exports are CC0-1.0 generated data, exported from CharacterCreator revision 852e48f316b90a0937234886630e4fb4cdfd1f78. See manifest.json (hashes, sources, licenses) and SOURCE-LICENSE-NOTES.md. All configurations are saved as .settings.json for reproducibility. These are manually selected synthetic adult presets, not actual user likenesses.

The GPL character generator was run only as an external build-time tool in task scratch. Its JavaScript/runtime code is not bundled in this application. Runtime animation is our native Three.js AnimationMixer integration. CC0 baked clips: idle, idle_look, walk, run; 53 bones. Own seated pose uses the actual skeletal joints. Textures are embedded, maximum 1024 pixels, no runtime CDN/API requests.

A user photo is still a locally fitted 3D face projection, not a full photorealistic head reconstruction. The game does not claim exact identity reconstruction from one image. Body type is selected manually.
